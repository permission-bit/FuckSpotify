# OfflineMusic

OfflineMusic ist ein nativer Offline-Musikplayer für das iPhone. Die
Musikbibliothek bleibt lokal auf dem Gerät; es gibt kein Konto und keine
Pflicht zur Internetverbindung.

Enthalten sind eine SwiftUI/SwiftData-App, ein optionaler lokaler Mac Companion,
Dateiimport, Wiedergabe, Playlists, YouTube-Suche/-Vorschau und sichere
Übertragung autorisierter Dateien über HTTPS.
