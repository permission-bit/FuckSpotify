# OfflineMusic

OfflineMusic es un reproductor de música nativo y sin conexión para iPhone.
La biblioteca permanece en el dispositivo: no necesitas una cuenta ni una
conexión permanente a Internet.

Incluye una app SwiftUI/SwiftData, un Companion local opcional para Mac,
importación de archivos, reproducción, playlists, búsqueda/vista previa de
YouTube y transferencia HTTPS de archivos autorizados.

Documentación completa en inglés: [README.md](README.md)
