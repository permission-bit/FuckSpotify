# OfflineMusic

OfflineMusic est un lecteur de musique natif hors ligne pour iPhone. La
bibliothèque reste sur l’appareil : aucun compte ni connexion Internet
permanente n’est nécessaire.

Le projet comprend une app SwiftUI/SwiftData, un Companion Mac local optionnel,
l’importation de fichiers, la lecture, les playlists, la recherche/aperçu
YouTube et le transfert HTTPS de fichiers autorisés.

Documentation complète en anglais : [README.md](README.md)
