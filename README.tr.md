# OfflineMusic

OfflineMusic, iPhone için yerel çalışan bir müzik oynatıcıdır. Müzik arşivi
cihazda kalır; hesap veya sürekli internet bağlantısı gerekmez.

Projede SwiftUI/SwiftData uygulaması, isteğe bağlı yerel Mac Companion, dosya
aktarma, oynatma, çalma listeleri, YouTube arama/önizleme ve yetkili dosyalar
için güvenli HTTPS aktarımı bulunur.
