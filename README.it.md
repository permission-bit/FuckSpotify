# OfflineMusic

OfflineMusic è un lettore musicale nativo offline per iPhone. La libreria resta
sul dispositivo: non servono account né una connessione Internet permanente.

Include un’app SwiftUI/SwiftData, un Companion locale opzionale per Mac,
importazione di file, riproduzione, playlist, ricerca/anteprima YouTube e
trasferimento HTTPS di file autorizzati.

Documentazione completa in inglese: [README.md](README.md)
