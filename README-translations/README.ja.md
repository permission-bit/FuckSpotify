# jox

jox は iPhone 向けのネイティブなオフライン音楽プレーヤーです。
音楽ライブラリは端末内に保存され、アカウントや常時インターネット接続は
必要ありません。

SwiftUI/SwiftData アプリ、任意で使えるローカル Mac Companion、ファイルの
読み込み、再生、プレイリスト、YouTube 検索・プレビュー、認証済みファイルの
安全な HTTPS 転送を含みます。

アーティスト別にお気に入りを表示したり、オフラインで音楽を再生したりできます。
音声の指定範囲をプレビューして、残すか切り取るかを選べます。
