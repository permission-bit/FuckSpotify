# OfflineMusic

OfflineMusic é um player de música nativo e offline para iPhone. A biblioteca
fica no dispositivo: não é necessária uma conta nem conexão permanente com a
Internet.

O projeto inclui um app SwiftUI/SwiftData, um Companion local opcional para Mac,
importação de arquivos, reprodução, playlists, busca/prévia do YouTube e
transferência HTTPS de arquivos autorizados.
