# OfflineMusic

OfflineMusic is een native offline muziekspeler voor iPhone. Je bibliotheek
blijft op het apparaat; een account of permanente internetverbinding is niet
nodig.

Het project bevat een SwiftUI/SwiftData-app, een optionele lokale Mac Companion,
bestandimport, afspelen, afspeellijsten, YouTube zoeken/voorvertonen en veilige
HTTPS-overdracht van geautoriseerde bestanden.
