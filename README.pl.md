# OfflineMusic

OfflineMusic to natywny odtwarzacz muzyki offline na iPhone’a. Biblioteka
pozostaje na urządzeniu; konto ani stałe połączenie z internetem nie są
wymagane.

Projekt zawiera aplikację SwiftUI/SwiftData, opcjonalny lokalny Companion dla
Maca, import plików, odtwarzanie, playlisty, wyszukiwanie/podgląd YouTube oraz
bezpieczny transfer autoryzowanych plików przez HTTPS.

Pełna dokumentacja po angielsku: [README.md](README.md)
