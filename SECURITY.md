# Security policy

## Supported versions

Only the latest `main` branch is currently maintained. This is an early-stage
project and does not promise security updates for old releases.

## Reporting a vulnerability

Please do not open a public issue for credentials, TLS bypasses, arbitrary file
access, token exposure or other security-sensitive bugs. Contact the repository
maintainer privately through the GitHub security-advisory mechanism or the
private contact method listed on the repository profile.

Include the affected commit or release, reproduction steps, impact and a safe
way to reproduce the issue without sharing personal music or credentials.

Do not include API keys, pairing secrets, certificate private keys, Keychain
data or personal files in a report.
